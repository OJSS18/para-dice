# Para-DICE v0.8.2 - archived code

A snapshot of the code exactly as it was at v0.8.2, before the new PIPS game mode
was added. The same version is also tagged in git as `v0.8.2`.

The pictures, fonts and sounds didn't change, so they aren't copied here.
To run this version: copy the `assets` folder from the main project into this
folder, then run `love .` here.
